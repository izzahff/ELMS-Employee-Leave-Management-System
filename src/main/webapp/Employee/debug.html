🐛 COMMON ISSUES & FIXES

🔥 Issue 1: No AJAX Call Made

Symptom: No "AJAX Call Starting" message in console

Cause: JavaScript error preventing event handler

Fix: Look for JavaScript errors in red in console

🔥 Issue 2: AJAX Call Fails

Symptom: AJAX call starts but fails

Cause: Wrong URL or session expired

Fix: Check Network tab for actual request/response

🔥 Issue 3: Response Parsing Fails

Symptom: "JSON Parse Error" in console

Cause: Server returned HTML instead of JSON

Fix: Check if you're still logged in

🔥 Issue 4: Dropdown Not Populated

Symptom: AJAX works but dropdown stays empty

Cause: DOM manipulation error

Fix: Check if leaveTypeSelect element exists
